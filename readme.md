# Cute Midnight Sky Birthday Website

## Cara Menjalankan Lokal (Preview Live Server)
1. Buka folder `birthday-website` di Visual Studio Code.
2. Install ekstensi **Live Server** (oleh Ritwick Dey).
3. Klik kanan pada file `index.html` dan pilih **Open with Live Server**.
4. Website akan terbuka di browser Anda secara otomatis!

## Cara Deploy ke Vercel (Gratis & Mudah)
1. Buka GitHub (github.com), buat repository baru misal `my-birthday-web`.
2. Upload seluruh isi folder `birthday-website` (termasuk folder css, js, assets) ke repository tersebut.
3. Buka [Vercel.com](https://vercel.com) dan login menggunakan akun GitHub Anda.
4. Klik **Add New...** > **Project**.
5. Import repository `my-birthday-web` yang baru dibuat.
6. Pada bagian "Framework Preset", biarkan **Other**.
7. Pada "Build and Output Settings", tidak perlu mengubah apa-apa.
8. Klik **Deploy**.
9. Selesai! Vercel akan memberikan URL publik untuk website Anda (contoh: `my-birthday-web.vercel.app`).
